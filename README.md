# 펼침 뷰어

갤럭시 Z 폴드를 펼치면 두 쪽, 접으면 한 쪽으로 보여 주는 만화·문서 뷰어예요.
PDF, 사진 여러 장, ZIP/CBZ 만화를 열 수 있고, 파일은 폰 안에서만 열려요.

- 접기/펼치기에 맞춰 1쪽·2쪽 자동 전환
- 만화책(오른쪽 → 왼쪽), 문서·책(왼쪽 → 오른쪽) 넘김 방향
- 책장 넘김 효과 (탭하거나 손가락으로 끌기)
- 책장: 여러 권을 꽂아 두고, 책마다 읽던 쪽에서 이어 읽기
- 홈 화면에 추가하면 전체화면 앱으로 실행, 한 번 연 뒤에는 오프라인 사용

## 설치

폰 브라우저(Chrome, 삼성 인터넷)로 https://xylon-b.github.io/fold-viewer/ 를 열고 메뉴에서 **홈 화면에 추가**(또는 **앱 설치**)를 누르세요.

## 수정할 때

`tools/fold-viewer.html`이 원본이에요. 고친 뒤 `python3 tools/build_app.py <libs>`로 `index.html`을 다시 만들어요.
